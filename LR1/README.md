### Особенности зон
  - **.ru и .рф** — обязательная привязка к российским данным (при регистрации или продлении могут потребоваться подтверждающие документы).
  - **.spb.ru** — зона для зарегистрированных в Санкт-Петербурге или связанных с городом.
  - **.com, .net, .org** — международные зоны, регистрация возможна через большинство регистраторов без дополнительных требований.
  - **.dev** — новая зона, связана с разработчиками, обычно доступна для регистрации через основные регистраторы.
